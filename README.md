Aplicación web desarrollada con Flask y una **base de datos relacional**, enfocada en demostrar la creación de aplicaciones web dinámicas utilizando Python, HTML y SQL.

## 📖 Descripción

Este proyecto implementa una aplicación web utilizando el framework **Flask**, donde se integra una base de datos para realizar operaciones de consulta y administración de información.

El objetivo es comprender cómo conectar una aplicación desarrollada en Python con una base de datos, permitiendo realizar operaciones CRUD (Crear, Leer, Actualizar y Eliminar) mediante una interfaz web.

## ▶️ Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/IDGS-804-23002222/FLASKBDIDGS804.git
```

### 2. Entrar al proyecto

```bash
cd FLASKBDIDGS804
```

### 3. Crear un entorno virtual (opcional)

```bash
python -m venv venv
```

### 4. Activar el entorno

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

### 5. Instalar dependencias

```bash
pip install -r requirements.txt
```

### 6. Ejecutar la aplicación

```bash
python app.py
```

La aplicación estará disponible en:

```
http://127.0.0.1:5000/
```
